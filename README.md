# Concord

Chat, voz, câmera e compartilhamento de tela para a galera.

## [⬇ Baixar o Concord para Windows](https://github.com/MikaelFM/Concord/releases/latest/download/Concord-Instalador.exe)

Abra o arquivo baixado e siga a instalação. Se aparecer "O Windows protegeu o computador", clique em **Mais informações → Executar assim mesmo**.
Depois de instalado, o app se atualiza sozinho.
